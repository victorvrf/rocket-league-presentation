# Skill Replay Clips (Slide 7)

Slide 7 plays one gameplay clip per skill stage. Drop the files below into this folder using these exact names:

| Stage | File | Skill shown |
|---|---|---|
| 01 | `drive.mp4` | Basic driving and positioning |
| 02 | `hit-the-ball.mp4` | First contact / reading the bounce |
| 03 | `ball-control.mp4` | Dribbling and ball manipulation |
| 04 | `aerial-control.mp4` | Aerials and air control |
| 05 | `advanced-mechanics.mp4` | Advanced mechanics / creative options |
| 06 | `consistency.mp4` | Consistent execution under pressure |
| 07 | `supersonic-legend.mp4` | Supersonic Legend highlight (culmination) |

## Clip guidelines

- Format: MP4 (H.264 + AAC or silent), 1080p or higher, 16:9.
- Length: 6–12 seconds, loop-friendly (clean in/out points).
- Style: esports replay/highlight — no game UI overlays, no watermarks.
- Footage should be slightly dark or contrasty so the slide's overlay keeps text readable.
- For the culmination clip (`supersonic-legend.mp4`), use the most impressive highlight available; the slide adds a gold glow treatment automatically.
- Optional: pre-apply slight slow motion to the key moment of each clip in your editor.

## Behavior without clips

If a file is missing, the slide silently falls back to the static aerial image with its Ken Burns motion — nothing breaks. Once a file is added, it fades in automatically the next time that stage is shown. A missing file is only requested once per session (no repeated 404 spam).
